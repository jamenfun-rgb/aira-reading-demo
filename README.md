# AIRA: AI Reading Assistant Demo

AIRA is an AI reading assistant prototype that opens as if a user has signed into their reading companion account. The demo shows a visible companion, a resumed reading session, guided comprehension support, and accessibility directions such as voice, captions, and future sign-support mode.

## View locally

Open `index.html` in a browser.

## Publish with GitHub Pages

1. Create a public GitHub repository.
2. Upload `index.html` and this `README.md`.
3. Go to repository `Settings`.
4. Open `Pages`.
5. Under `Build and deployment`, choose `Deploy from a branch`.
6. Choose the `main` branch and `/root`.
7. Save.
8. Use the GitHub Pages URL as the public demo link.

## OpenAI Showcase note

This static demo is the visual concept demo. The fuller project also includes a Node.js backend and OpenAI Responses API integration for live AI answers.
